# Amadeus SpriteForge

Amadeus SpriteForge is the rendering and behavior-runtime toolchain used by
[Amadeus](https://github.com/Code-Amadeus/Amadeus) for graph-driven character
animation and KTX2 runtime packages.

> **Status:** public namespace placeholder. The reviewed runtime, authoring
> tools, schemas, and documentation have not been published here yet.

The planned public scope is:

- behavior-graph and animation-intent runtime contracts;
- KTX2 package validation and deterministic asset metadata;
- renderer integration and portable preview tooling;
- authoring/export utilities that contain no private source artwork.

Personal character packs, source artwork, voice material, generated caches,
session data, and assets without redistribution rights will not be imported.

Until the first reviewed source release adds an explicit license, this
repository does not grant permission to use, modify, or redistribute future
code or media. Release planning and general discussion currently live in the
[main Amadeus repository](https://github.com/Code-Amadeus/Amadeus).
