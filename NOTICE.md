# Source provenance

This foundation was assembled on 2026-09-14 from the maintainer's SpriteForge
authoring tools and the Amadeus character-pack contract.

| Component | Origin | Adaptation |
| --- | --- | --- |
| `src/spriteforge/qa.py` | SpriteForge `art_asset_platform.py` | Generic character metadata, flat-folder QA |
| `src/spriteforge/web/review.*` | SpriteForge `art_asset_review_gui.py` | Separate web assets; exact frame selection, validation, clip preview |
| `src/spriteforge/character_pack.py` | Amadeus `render/character_pack.py` | Explicit pack root, no application imports, stronger containment |
| `schemas/character-pack-v1/` | Amadeus schemas of the same name | Existing v1 contract retained |
| Other modules, tests, docs, demo | This repository foundation | Workspace and export integration |

This is a maintainer working-tree extraction, not a claim that every imported line
existed at a particular published Amadeus commit. The package format identifier
is retained for compatibility. Contract changes need verification against Amadeus.

Demo PNGs are geometric primitives generated by `spriteforge.demo`. Reviewer
screenshots illustrate a separately supplied character pack; that character's
artwork is not covered by the project's AGPL grant. Selected normalized character
reference stills are published in `examples/references/kurisu/`, with their provenance
described there, and remain outside the code/demo AGPL grant. The full character
pack, private workspace records, API credentials and model weights are not included.
Bundled browser JS/WASM retains its upstream licenses; see
THIRD_PARTY_NOTICES.md. Project code and generated demo use AGPL-3.0-only;
import/export does not change the license of user media.
